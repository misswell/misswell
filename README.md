## 🚀 精选项目

### [MacPilot](https://github.com/misswell/MacPilot) —— 开源 macOS 菜单栏效率工具箱

Swift 原生、零第三方依赖，一个应用装下 11 个日常功能：

- 按应用的自动退出 / 启动规则（闲置自动隐藏、关窗、退出）
- iPhone / Apple Watch 蓝牙靠近解锁 Mac（RSSI 双阈值）
- 窗口切换器（⌥Tab）、剪贴板历史（⌘⇧V）
- 平滑滚动、画中画、截图贴图、录屏（HDR）
- 输入法自动化、Finder 右键菜单、APFS 透明压缩

Apple 公证签名，免费使用 → **[下载最新版](https://github.com/misswell/MacPilot/releases/latest)**
